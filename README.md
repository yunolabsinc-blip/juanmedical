# 주안메디칼

의료기기 유통 · 의약품 CSO · 비급여 제품 컨설팅 기업 홈페이지.

- 운영 도메인: https://www.juanmedical.kr/
- 기존 Vercel 프로젝트: juanmedical
- HTML / CSS / JavaScript 정적 사이트, 별도 빌드나 패키지 설치 불필요

## 파일 구성

- index.html: 회사 소개, 사업영역, 핵심역량, 문의 양식, 검색/공유 메타데이터
- styles.css: 공식 로고의 로열 블루·화이트·실버 디자인과 반응형 화면
- script.js: 모바일 메뉴, 사업별 문의 분야 선택, 이메일 작성 내용 확인 및 복사
- assets/: 기존 공식 로고와 파비콘, 새 브랜드 콘셉트 이미지

## 문의 동작

폼 작성 후 필수 입력과 이메일 형식을 검사하고 작성 내용 확인 창을 표시합니다. 사용자가 이메일 앱에서 직접 전송해야 문의가 전달됩니다. 수신 주소는 juanmedicalkorea@gmail.com입니다. 서버 저장이나 자동 발송 기능은 없으며, 이메일 앱이 없는 경우를 위해 복사 버튼을 제공합니다.

메인 비주얼은 실제 병원·제품 사진이 아닌 생성형 추상 이미지입니다.
